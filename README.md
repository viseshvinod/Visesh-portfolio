# Visesh AV - Portfolio

A single-page portfolio built with plain HTML, CSS and a little JavaScript. No build step.

## Run it
Open `index.html` in any browser.

## Host it
Upload `index.html` to any static host (GitHub Pages, Netlify, Vercel, Cloudflare Pages).
For GitHub Pages: push the file to a repo named `<username>.github.io`, or enable Pages on the repo.

## Edit it
- Text lives in `index.html`. Search for the section ids: projects, experience, skills, education, contact.
- Colors and fonts are tokens at the top of the `<style>` block (`--accent`, `--c-cv`, `--c-nlp`, `--c-data`, `--c-ml`).
- Fonts load from Google Fonts, so the page needs an internet connection to show them. It falls back to system fonts offline.
